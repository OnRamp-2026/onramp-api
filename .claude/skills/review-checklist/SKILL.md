# 코드 리뷰 (/review-checklist)

`docs/dev-workflow/verification-loop.md`의 **프로젝트 고유** 체크리스트를 적용한다.

> 순서: 먼저 빌트인 `/code-review`로 일반 리뷰 → 이 스킬로 이 레포만의 항목 점검.
> 더 독립적인 판단이 필요하면 `code-reviewer` 서브에이전트에 위임한다(격리 컨텍스트 → `docs/dev-workflow/roles.md`).

## 절차
1. 대상 파악(`git diff` 또는 지정 파일).
2. 체크리스트 점검:
   - [ ] 버그·논리 오류·엣지케이스 누락
   - [ ] 보안(인증·입력검증·비밀 노출)
   - [ ] 성능(불필요 반복·N+1·메모리)
   - [ ] 기존 패턴과 일관·불필요한 복잡도
   - [ ] 테스트가 실제 동작 검증(무의미한 통과 아님)
   - [ ] 계획서 대비 범위 이탈 없음

## 출력
- 발견 항목을 **심각도(높음/중간/낮음)** + 위치(파일:줄) + 문제 + 개선안으로. 없으면 "이상 없음".
- 자동 수정하지 않고 **보고**. 수정은 승인 후.
