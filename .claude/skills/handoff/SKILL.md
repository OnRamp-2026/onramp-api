# 인수인계 (/handoff)

세션이 길어졌거나 끝날 때, 다음 사람/세션이 바로 이어받도록 요약한다.

## 출력 → `docs/handoff/<YYYY-MM-DD>.md`
```
## 무엇을 하려 했나
<목표/작업>

## 지금까지 한 것
<완료 항목 + 관련 파일>

## 현재 상태
<동작하는 것 / 미완 / 알려진 이슈>

## 다음 할 일
<우선순위 순 next steps>

## 검증 상태
<테스트/타입체크 통과 여부, 남은 검증>

## 참고
<계획서 경로, 결정 이유, 주의점>
```

## 규칙
- 사실만(추정 금지). 미검증·미완은 그대로 표시.
- 커밋·push는 사람 승인 후. 이 문서는 커밋해도 됨(진행 기록).
