# 승인된 계획 구현 (/implement-from-plan)

> **승인된 계획만** 구현한다. 계획서가 없거나 미승인이면 → 먼저 `/research-plan`.

## 입력
승인된 계획서 경로(`docs/plans/<날짜>-<기능>.md`).

## 절차
1. 계획서를 읽고, **승인 여부 확인.** 미승인이면 구현 거부하고 승인 요청.
2. 계획의 단계 순서대로 구현. **계획에 없는 변경은 하지 않는다**(발견 시 계획 수정 제안 → 승인 후).
3. 각 단계 후 관련 검증(테스트/타입체크) 실행(→ `docs/dev-workflow/verification-loop.md`).
4. `.env`·시크릿 미접근. 위험 명령 금지.

## 출력
- 코드 변경 + 변경 요약(무엇을·왜, 계획 대비 이탈 여부). **커밋은 검증 통과 후, push는 사람 승인.**
