# TDD (/tdd)

> 실패 테스트를 먼저 쓰면 "코드가 해야 할 일"의 계약이 생긴다. AI에게 구체적 목표 + 검증 수단을 동시에 준다.

## 절차
1. 기능에 대한 **실패하는 테스트**를 먼저 작성(정상·엣지·실패 경로).
2. 실행해 **실패 확인**(빨간불). 테스트를 **커밋**(구현 전).
3. 테스트를 통과시키는 **최소 구현**.
4. 모든 테스트 **통과 확인**(초록불).
5. 필요하면 리팩터 — 테스트가 계속 통과하는지 확인(→ `refactor-clean`).
6. **테스트 리뷰** — `assert true` 같은 무의미한 통과가 아닌지.

## 출력
- 실패 테스트 커밋 → 구현 → 통과. 커버 케이스 목록.
